# 🚀 DÉMARRAGE RAPIDE

## 3 Étapes Simples

### ✅ Étape 1: Installer
```bash
npm install
```

Si des erreurs apparaissent, c'est normal! Continuez à l'étape 2.

### ✅ Étape 2: Lancer
```bash
npm start
```

Vous verrez: `Server running on http://localhost:3000`

### ✅ Étape 3: Ouvrir
Allez à: **http://localhost:3000**

## 📱 Première Utilisation

### Créer un événement:
1. Allez dans "Événements"
2. Cliquez "+ Nouvel événement"
3. Remplissez les champs
4. Cliquez "Créer l'événement"

### Ajouter des invités:
1. Allez dans "Invités"
2. Cliquez "+ Nouvel invité"
3. Remplissez les infos
4. Sélectionnez l'événement
5. Cliquez "Ajouter"

### Réserver une salle:
1. Allez dans "Salles"
2. Sélectionnez une salle
3. Choisissez les dates
4. Cliquez "Réserver"

## 🐛 Problèmes Courants

### "npm: command not found"
→ Installez Node.js depuis https://nodejs.org/

### "Port 3000 already in use"
→ Utilisez: `PORT=3001 npm start`

### "Cannot find module 'sqlite3'"
→ Exécutez: `npm install sqlite3`

### "Cannot GET /"
→ Attendez quelques secondes et rechargez la page
